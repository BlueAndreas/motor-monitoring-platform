# 验证说明

验证环境为 Windows、Python 3.14.4、.NET 8 SDK。依赖固定为 paho-mqtt 2.1.0 和 PyModbus 3.11.4。

## 已验证

- 四项 Python 检查：寄存器缩放、持续过温与过流、短时尖峰恢复、冻结及采样序号回绕。
- C# 项目成功构建，六项逻辑自检：首次有效采样、14 秒未更新、16 秒过期、通信失败、非法运行状态、序号回绕。
- 实际运行本机 Modbus 模拟服务，Python 和 C# 能读取相同六个寄存器。
- 停止模拟器后，C# 输出 `comm_ok=0`、`data_valid=0`。
- 本机临时 MQTT 协议测试服务收到三条消息，主题、JSON、序号和 QoS 1 发布确认符合预期。
- Docker Compose 配置静态解析。

运行方式见仓库 README。协议检查脚本使用临时本机服务，不连接外部设备；临时 MQTT 服务只覆盖检查所需的报文，不能代替完整消息代理。

## 尚需验证

- ThingsBoard 镜像启动、数据库初始化、网页登录和遥测入库。
- 真实 IoTGateway 编译运行及完整 Modbus → 网关 → ThingsBoard 联调。
- HealthWatcher HTTP 上传至 ThingsBoard 的链路。
- 实时看板与平台告警的触发、确认和恢复。
- 长时间持续运行、吞吐量、真实电机或 PLC 接入。

模拟器数值用于演示数据链路，原型阈值未经过现场设备标定。本仓库没有工业现场部署、性能达标或平台告警已完成的验证记录。
